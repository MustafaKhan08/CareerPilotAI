## Setup

1. Clone the repository

```bash
git clone https://github.com/<username>/CareerPilotAI.git
```

2. Create a `.env` file

Copy:

```text
backend/.env.example
```

to:

```text
backend/.env
```

3. Fill in your credentials.

4. Install dependencies.

5. Run Alembic migrations.

6. Start the FastAPI server.
